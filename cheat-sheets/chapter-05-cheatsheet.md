## Chapter 5: Exam Day Victory: Strategies, Practice Tests & Final Review — Quick Reference

### Core Concepts
| Concept | One-line explanation |
|---------|---------------------|
| Exam Format | 40-60 questions, 45-60 minutes, 700/1000 to pass |
| Question Types | Multiple choice, drag-and-drop, case studies, yes/no series |
| Three Domains | Cloud Concepts (25-30%), Azure Services (35-40%), Security/Governance (30-35%) |
| Scenario Questions | Real-world situations requiring concept application, not memorization |
| Elimination Technique | Remove obviously wrong answers to improve odds on uncertain questions |

### Key Syntax / Commands
```
EXAM TIME FORMULA:
- 60 minutes ÷ 50 questions = ~1.2 min/question
- Flag difficult questions, move on, return later
- Reserve 5-10 minutes for review

PASSING CALCULATION:
- 700/1000 = 70% minimum
- ~35-42 correct answers needed (varies by question weighting)
```

### Common Patterns
**Pattern 1: Scenario Question Approach**
Read the requirement FIRST → Identify key constraints (cost, compliance, availability) → Match to Azure service

**Pattern 2: Elimination Strategy**
Cross out answers with absolute words ("always," "never") → Remove out-of-scope services → Choose most specific remaining answer

### Things to Remember
✅ Understand WHY services exist, not just definitions
✅ Read every word—"most cost-effective" vs "fastest" changes the answer
✅ Management Groups > Subscriptions > Resource Groups > Resources (hierarchy)
❌ Don't change answers unless you find a clear error—first instinct is often correct
