### Key Terms

| Term | Definition |
|------|-----------|
| Domain Weighting | The percentage of exam questions allocated to each major topic area |
| Scenario-based Question | Question type presenting a business situation requiring you to select the appropriate Azure solution |
| Flagging | Marking questions during the exam to revisit before final submission |
| Elimination Technique | Strategy of removing clearly incorrect answers to improve selection odds |
| Passing Score | The minimum score required to pass (700/1000 for AZ-900) |
| Proctored Exam | Supervised exam either at a testing center or online with remote monitoring |
| Role-based Certification | Advanced Azure certifications focused on specific job roles (Admin, Developer, Architect) |

### Memory Tricks
- **"700 Club"**: Remember passing is 700 points—you can miss 30% and still pass, so don't panic over tough questions
- **"AAS" for Domains**: Cloud concepts (A-bout cloud), Architecture/Services (A-zure stuff), Management/governance (S-upervision) — weighted approximately 25-40-35
- **"STOP and FLAG"**: When stuck, **S**kip, **T**ag it, **O**ptimize remaining time, **P**roceed — return to flagged items later
- **"Best Fit, Not Perfect Fit"**: For scenario questions, you're finding the BEST answer among options, not the theoretically perfect solution
